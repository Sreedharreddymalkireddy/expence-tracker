# Expense Tracker

A simple responsive Expense Tracker built with React.js, JavaScript, HTML5 and CSS3.

## Features

- Add income and expense transactions
- Edit transactions
- Delete transactions
- Categorize transactions
- Filter by All, Income or Expenses
- Calculate current balance, total income and total expenses
- Save transactions in browser LocalStorage
- Data remains after page refresh
- Responsive design for desktop and mobile

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Browser LocalStorage
- Vite

## Run the project

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Build check

```bash
npm run build
```

The production build is generated in the `dist` folder.
